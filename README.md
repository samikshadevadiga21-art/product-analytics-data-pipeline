# Product Analytics – Data Engineering Pipeline

A product analytics project that extracts product data from the DummyJSON API, processes it using Python and Pandas, and visualizes insights through an interactive Power BI dashboard.

## Technologies Used
- Python
- DummyJSON API
- Pandas
- CSV
- Power BI

## Key Features
- API data extraction
- Data cleaning and transformation
- Product price and category analysis
- Rating and discount analysis
- Interactive Power BI dashboard

## Project Files
- `product_analytic_dashboard.pbix` – Power BI Dashboard
- `final_products.csv` – Processed Dataset
